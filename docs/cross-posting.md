# DEV cross-posting policy

`mutunda.me` is the canonical source for technical writing. Publish the complete
article here first, verify its generated `/writing/<slug>/` URL, then cross-post
to DEV Community.

When publishing on DEV:

1. Use the same title and a concise excerpt suitable for DEV readers.
2. Set DEV’s canonical URL field to the original `https://mutunda.me/writing/<slug>/` URL.
3. Do not add a different canonical URL to the mutunda.me article unless it has
   intentionally moved to another primary domain.
4. Update the original article first; make any DEV revision a cross-post of that
   source rather than a competing version.

The site emits self-referential canonicals, RSS items, sitemap entries, and
article metadata from the same source files. A DEV canonical tells search engines
that the cross-post is a secondary copy.
